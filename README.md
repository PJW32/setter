### 심사위원 접속 안내

- 심사용 배포는 로그인 없이 접속하는 공개 모드로 운영합니다. 로그인 창이 뜨면 **아이디·암호는 과제 제출서에 따로 적었습니다.** (이 공개 저장소에는 적지 않습니다)
- 무료 서버라 15분 동안 접속이 없으면 잠듭니다. **첫 접속은 1분 정도 걸릴 수 있습니다.**
- 처음 검색하는 목적지는 주변 지역 데이터를 그 자리에서 모으므로 첫 응답이 오래 걸릴 수 있습니다. 작업 로그에서 진행 상황을 볼 수 있습니다.
- 개인정보(이름·연락처 등)는 입력하지 마세요. 입력한 문장은 AI(Gemini)로 전송됩니다.

**시연 순서 예시** (판교 IT 회사에 합격한 지방 출신 신입 가정)

1. `판교역으로 출근해요. 보증금 1000에 월세 60 넘으면 안 되고 통근은 50분 이내였으면 해요. 싼 게 제일 중요하고 조용했으면 좋겠어요. 이웃이 친절했으면 좋겠어요.`
2. `아까보다 역 가까운 게 더 중요해요. 통근보다는 역이 더 중요해요.` → 순위가 바뀐 이유 확인
3. `통근 30분 이내로 줄이면 어떻게 돼?` → 실제 조건은 그대로 둔 가정 결과
4. `1위랑 3위 비교해줘`, `그 동네 치안은 어때?` → 비교표, 데이터가 없는 정보의 확인 방법

## 문제 정의

- **대상 사용자**: 취업·이직·교육으로 생활권을 옮기는 청년 중, 목적지는 정했지만 거주지는 정하지 못한 사람
  - 주요 사용자: 첫 출근을 앞둔 신입. 예: 판교에 취업해 첫 자취를 준비하는데, 보증금·월세 상한은 알지만 어느 동네에서 출퇴근이 가능한지 판단하기 어려운 청년
  - 보조 사용자: 청년 취업·교육 기관에서 초기 정착 정보를 안내하는 담당자
- **문제**: 부동산 앱은 매물 중심이라, 어느 동네가 내 예산·통근·생활 조건에 맞는지 비교하려면 지도·실거래가·경로 앱을 오가며 직접 계산해야 합니다. 월세만 보고 고르면 보증금과 교통비를 합친 실제 월 지출을 놓치기 쉽습니다.
- **해결**: 조건을 말로 하면 에이전트가 해석을 먼저 보여 주고, 공공데이터와 지도 API로 동네(법정동)별 값을 모은 뒤 코드가 점수를 계산해 순위·지도·비교표로 보여 줍니다. 매물은 추천하지 않고 동네를 중립적으로 비교합니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 자연어 조건 입력 | 예산·통근·선호를 한 문장에 여러 개 말해도 됨. "60 넘으면 안 돼"(필수 조건)와 "싸면 좋겠어"(선호)를 구분 |
| 해석 확인 카드 | "이렇게 이해했어요": 필수 조건, 요인별 중요도와 근거 원문, 버린 항목과 이유, 데이터로 확인할 수 없는 조건 |
| 되묻기 | 목적지가 없거나, 못 찾았거나, 조건끼리 상충하면 다시 물어봄 |
| 목적지 해석 | 역·동네·회사 이름을 가장 가까운 지하철역에 연결 (예: 회사 이름 → 판교역 + 도보 2분) |
| 실시간 지역 수집 | 처음 보는 목적지는 주변 시군구의 동 목록·시설·실거래·통근을 그 자리에서 수집해 저장. 진행 과정을 작업 로그로 표시 |
| 동네 순위 | 5개 요인 가중합 점수와 요인별 기여도. 필수 조건을 넘는 동은 제외 이유와 함께 따로 표시, 조금만 풀면 들어오는 동 안내 |
| 지도·산점도 | 점수 색 지도와 TOP 3 핀, 가로 월 총비용 × 세로 통근 시간 산점도(파레토 강조) |
| 후보 비교 | 월 총비용 분해(월세·보증금 환산·교통비), 통근 경로, 출처, 매물 사이트 연결을 한 장의 비교표로 |
| 순위 변동 설명 | 조건을 바꾸면 무엇이 바뀌어 어느 동이 몇 점 움직였는지 요인별로 분해해 설명 |
| 가정 질문 | "~하면 어떻게 돼?"는 결과만 보여 주고 실제 조건은 유지 |
| 질문 답변 | 특정 동·순위 비교·'그 동네' 질문에 재계산 없이 지금 결과로 답변 |
| 확인 방법 안내 | 치안·관리비·소음처럼 데이터가 없는 정보는 지어내지 않고 확인할 곳(생활안전지도, 인터넷등기소 등)을 안내 |

전체 기능 목록과 수용 기준: [docs/feature-spec.md](docs/feature-spec.md)

## 차별점

1. **매물 없이 동네를 중립 비교**: 플랫폼 AI는 자기 매물 안에서 추천하지만, 새터는 매물 없이 동네 단위로 비교하고 매물 사이트는 링크로만 연결합니다.
2. **월 총비용으로 비교**: 월세 + 보증금 × 환산이율 ÷ 12 + 월 교통비
3. **시간 vs 돈 트레이드오프 시각화**와, 대화로 조건을 바꿨을 때 **순위가 바뀐 이유** 설명
4. **AI가 해석을 먼저 보여 주고 확인받음**. 데이터로 확인할 수 없는 조건은 "확인 불가"로 분리

## 동작 방식

```
사용자 발화
  → [Gemini]  현재 조건 + 새 발화 → 조건·중요도 변경분 (JSON 스키마 강제)
  → [코드]    변경분 검증, "A가 B보다 중요" 순서 검사·교정
  → [카카오]  목적지 → 가장 가까운 지하철역
  → [수집]    후보 지역이 없으면 공공데이터·카카오 API로 수집 후 SQLite 저장
  → [엔진]    필수 조건 필터 → 정규화 → 가중합 → 요인별 기여도 → 순위 변동 분해
  → [Gemini]  엔진이 계산한 값만으로 설명 작성 → 설명 속 숫자를 코드로 검사
  → 화면      해석 카드 · 작업 로그 · 지도 · 순위표 · 산점도 · 비교표
```

**LLM은 양 끝(입력 해석, 결과 설명)에만 쓰고, 점수 계산은 전부 코드가 합니다.** 같은 데이터와 같은 조건·가중치가 주어지면 엔진은 항상 같은 순위를 냅니다. 학습(파인튜닝)한 모델은 없습니다.

### 추천 요인

| 요인 | 방향 | 데이터 |
|---|---|---|
| 월 총비용 | 낮을수록 좋음 | 국토교통부 전월세 실거래가(원룸 33㎡ 이하, 신규 계약, 최근 12개월 동별 중앙값) + 카카오 대중교통 요금 |
| 통근 시간 | 짧을수록 좋음 | 카카오 대중교통 경로 |
| 역 접근성 | 가까울수록 좋음 | 카카오 지하철역 검색 (직선거리 기반 도보 추정) |
| 생활 편의 | 많을수록 좋음 | 카카오 카테고리 개수 (편의점·약국 500m, 대형마트 1.5km) |
| 조용함 | 주점이 적을수록 좋음 | 소상공인시장진흥공단 상가정보 주점(I211) 수 |

- 중요도는 5단계(매우 중요 4 · 중요 3 · 보통 2 · 조금 1 · 상관없음 0)이며, LLM은 숫자 대신 단계를 고르고 코드가 가중치로 바꿉니다. "필수"는 가중치가 아니라 후보를 거르는 조건으로 따로 처리합니다.
- 보증금 환산이율 5.0%: 엔진 설정값. 주택임대차보호법상 전환율 상한(기준금리 + 2%p)을 2026-11-20 기준금리 3.00%로 적용했습니다.
- 실거래 표본이 5건 미만인 동은 0점으로 처리하지 않고 "데이터 부족"으로 표시하고, 그 요인을 빼고 가중치를 다시 나눕니다.

상세: [docs/engine.md](docs/engine.md), [docs/data.md](docs/data.md)

## AI 활용과 오류 대응

| 구분 | 도구 | 용도 |
|---|---|---|
| 서비스 | Google Gemini `gemini-3.8-flash` (Vertex AI) | 발화 → 조건 변경분 추출(temperature 0.2), 대화 의도 분류, 결과·순위 변동 설명(temperature 0.3) |
| 개발 | OpenAI Codex | 자료 조사·기획 정리, 프론트엔드·백엔드 코드 |
| 개발 | Claude Code | 추천 모델(조건 추출·점수 엔진·설명 검증) 코드, 테스트·기술 문서 |
| 디자인 | OpenAI GPT 이미지 모델 | 마스코트·앱 아이콘 이미지 생성 (LLM으로 프롬프트 작성 후 입력) |

AI가 만든 코드는 팀원이 실행·테스트하고 Pull Request 리뷰를 거쳐 병합했습니다. 문제 정의, 서비스 구조, 추천 요인·가중치·산식, 프롬프트·스키마, 데이터 정제 규칙, 화면 설계는 팀이 정했습니다.

| AI 오류 위험 | 대응 |
|---|---|
| JSON 형식이 깨짐 | 스키마 강제, 실패 시 1회 재시도, 그래도 실패하면 다시 말해 달라고 안내 |
| 없는 요인·단계·조건 | 스키마 enum + 엔진이 다시 검증, 버린 항목과 이유를 화면에 표시 |
| 비교 순서를 거꾸로 반영 | "A가 B보다 중요"를 따로 받아 코드가 순서 검사·교정 |
| 설명에 없는 숫자를 지어냄 | 설명 속 숫자를 엔진 계산값과 대조 → 재작성 → 또 틀리면 코드 템플릿 설명으로 대체('자동 요약' 표시) |
| 확인할 수 없는 조건을 지어냄 | '확인 불가'로 분리하고 코드에 정의한 확인 방법·링크 안내 (정의되지 않은 주제는 카카오맵 검색 링크) |
| 해석이 사용자 의도와 다름 | 해석 카드에 근거 원문 표시, 목적지 후보 제시, 가정 질문은 실제 조건을 바꾸지 않음 |

**검증 결과**: 단위·회귀 테스트 133개 통과(가상 데이터, 네트워크 없음), 조건 추출·의도 분류 발화 24개 세트 24/24 통과(2026-11-22, 1회 실행), 판교 시나리오 실제 API 점검. 상세: [docs/backend.md](docs/backend.md), [docs/mvp-test-scenarios.md](docs/mvp-test-scenarios.md)

## 로컬 실행

필요: Python 3.12 이상, Node.js 24

```powershell
python -m pip install -r requirements.txt
Copy-Item .env.example .env      # 아래 키 입력
python config.py                 # 키 설정 여부 확인 (값은 출력하지 않음)

npm --prefix frontend install
npm --prefix frontend run build  # frontend/dist 생성

python -m uvicorn backend.main:app --port 8000
# http://localhost:8000
```

프론트엔드 개발 서버: `npm --prefix frontend run dev` → http://localhost:5173 (`/api`는 8000으로 프록시)

| 환경변수 | 필수 | 용도 |
|---|---|---|
| `GEMINI_API_KEY` | 필수 | 조건 추출·결과 설명. Agent Platform(Vertex)용 키 |
| `KAKAO_REST_API_KEY` | 필수 | 동 목록·대표 지점·역·편의시설·통근. 카카오맵 사용 설정 ON |
| `DATA_GO_KR_SERVICE_KEY` | 필수(월세) | 전월세 실거래가, 상가정보 |
| `ODSAY_API_KEY` | 선택 | 통근 교차 확인 (무료 한도 하루 약 30건) |

키는 `.env`에만 두며 `.env`는 깃에 올라가지 않습니다.

실제 API를 부르는 점검(키 필요, 사용량 발생): `python scripts/smoke_agent.py`(판교 3턴), `python scripts/eval_utterances.py`(발화 테스트 세트)

## 배포

`render.yaml` 기반 Render 무료 웹 서비스 1개로 배포합니다. 빌드 단계에서 국토부 실거래 스냅샷을 준비하고 프론트를 빌드하며, `DEPLOY_ACCESS_MODE`로 접속 방식을 고릅니다: `public`은 로그인 없이 접속하고, `basic`은 HTTP Basic 인증을 요구합니다(미설정 시 basic). 비밀값은 Render 환경변수에만 입력합니다. 상세: [docs/render-deploy.md](docs/render-deploy.md)

## 데이터 한계

- 실거래가는 **과거 계약**이며 현재 매물 가격이 아닙니다 (시세 참고용)
- 통근 시간은 출발 시각을 지정할 수 없는 추정값입니다
- 역 도보 시간은 직선거리 × 1.3 ÷ 분당 67m로 추정합니다
- 조용함은 주변 주점 수로 판단하는 대체 지표이며, 실제 소음을 잰 값이 아닙니다
- 동 대표 지점은 동 안의 생활 중심 한 점이라, 넓은 동은 위치에 따라 실제와 다를 수 있습니다
- 관리비·치안·채광·집 상태는 데이터가 없어 "확인 불가"로 안내합니다
- 카카오 대중교통 경로 무료 한도는 하루 1,000건이라, 처음 보는 목적지가 많으면 수집이 막힐 수 있습니다

## 개인정보·보안

- 실제 개인정보를 쓰지 않습니다. 시연·테스트 발화는 팀이 만든 가상 조건입니다.
- 입력창에 개인정보 입력 금지와 Gemini 전송 사실을 안내합니다.
- API 키·접속 암호는 환경변수로만 관리하며 저장소에 포함하지 않습니다.
- 배포 서버는 공개 모드에서도 서명 쿠키 기반 대화 소유 확인, 요청 수·동시 실행 제한, 1시간 미사용 세션 만료를 유지합니다. basic 모드에서는 접속 인증을 추가로 요구합니다.
