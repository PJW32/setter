# 기능 명세서

- 서비스: 첫동네 — 낯선 도시로 가는 청년에게 **매물이 아니라 살 동네**를 근거 있는 숫자로 추천하는 대화형 AI 에이전트
- 대상 사용자: 지방에서 졸업하고 수도권 회사에 합격한 신입 (예: 판교 IT 회사, 입사 2주 전, 수도권 지리를 모름)
- 범위: 1단계 **법정동 추천** (MVP). 세부 생활구역(H3 격자)은 확장
- 우선순위: **P0** 시연 필수 / **P1** MVP 포함 / **P2** 여유가 있으면
- 상태: ✅ = 구현 완료 (2026-11-21, 백엔드 단위 테스트 + 브라우저 확인)

## 3. 기능 상세

### F-01 자연어 조건 입력
- **설명**: 사용자는 모든 조작(조건 입력, 조정, 질문, 비교)을 대화로 한다. 한 문장에 여러 조건을 섞어 말해도 된다
- **입력**: 텍스트 (예: "판교역으로 출근해요. 보증금 1000에 월세 60 넘으면 안 되고 싼 게 제일 중요해요")
- **처리**: `POST /api/sessions/{id}/messages` → Gemini 가 현재 상태 기준 변경분 추출
- **화면**: 대화창 입력, 처리 중 입력 막기, 첫 화면에 예시 문장 3~4개(누르면 입력)
- **수용 기준**
  - 목적지·필수 조건·선호가 한 문장에 있어도 모두 반영된다
  - "아까보다 더/덜" 같은 상대 표현이 현재 단계에서 한 단계 움직인다
  - 발화 테스트 세트 18/20 이상 통과 ([mvp-test-scenarios.md](mvp-test-scenarios.md))

### F-02 해석 확인 카드 ("이렇게 이해했어요")
- **설명**: AI 가 자기 해석을 먼저 보여준다. 잘못 이해했으면 사용자가 바로 고쳐 말한다
- **데이터**: `interpretation` 이벤트
- **화면**: 발화 바로 아래 카드
  - 목적지: `destination.label`, 다른 후보(`alternatives`)
  - 필수 조건: `applied[type=constraint]` (전 → 후, 해제는 "해제")
  - 선호: `applied[type=preference]` 요인·단계 변화 + **근거 원문**(`evidence`)
  - 확인 불가: `unsupported[]` → "데이터로 확인할 수 없어 직접 확인이 필요해요" 체크리스트
  - 반영 못 함: `rejected[]` (이유)
  - 비교 교정: `comparison_fixes[]` ("월세가 통근보다 중요" → 코드가 순서 교정)
  - 가정 질문이면 "가정" 배지
- **수용 기준**: 근거 원문이 모든 선호 변경에 붙는다. "이웃이 친절했으면"은 확인 불가로만 나온다

### F-03 되묻기
- **설명**: 빠진 핵심 정보나 부딪히는 바람이 있으면 한 문장으로 묻는다
- **경우**: 목적지 없음 / 목적지를 지도에서 못 찾음 / 상충(편의시설 많고 조용한 곳)
- **데이터**: `interpretation.follow_up`, 마지막 `message`
- **수용 기준**: 목적지 없이 조건만 말하면 조건은 저장하고 목적지를 묻는다 (테스트 `test_asks_destination_first`)

### F-04 목적지 해석
- **설명**: "판교", "카카오 판교아지트", "을지로", "여의도" 같은 이름을 가장 가까운 지하철역에 붙인다. 역에서 장소까지 도보 시간은 통근에 더한다
- **처리**: "○○역" → 지하철역 / 동네 이름 → 주소 검색 / 그 밖 → 장소 검색 → 가장 가까운 역
- **화면**: 해석 카드에 "카카오판교아지트 (가까운 역: 판교역)", 지도에 목적지 핀
- **수용 기준**: [data.md](data.md) 2.1 의 예시 6개가 표대로 해석된다

### F-05 실시간 지역 수집 + 에이전트 작업 로그
- **설명**: 저장된 지역만 쓰지 않는다. 처음 보는 목적지면 반경 10km 의 시군구를 그 자리에서 수집해 저장한다. 에이전트가 무엇을 언제 했는지 실시간으로 보여준다
- **데이터**: `log` 이벤트 (step, status, detail, ms)
- **화면**: 타임라인. running 은 회전 아이콘, done 체크, warn 노랑, error 빨강, 소요 시간. 수집 중에는 "처음 보는 지역이라 데이터를 모으는 중 (몇 분 걸릴 수 있어요)" 안내
- **수용 기준**: 저장소가 빈 상태에서 판교역 시나리오가 끝까지 된다 (실측 약 4분), 두 번째부터는 수집 없이 15초 안팎

### F-06 동네 순위
- **설명**: 통과한 동을 점수(0~100) 순으로. 점수 = 요인별 기여 점수의 합
- **데이터**: `result.payload.ranked[]`
- **화면**: 표 — 순위, 동(시군구), 점수, **요인별 기여도 가로 누적 막대**(요인 색 고정), 월 총비용, 통근, 역 도보, 플래그 배지. 행을 누르면 F-17
- **수용 기준**: 막대 길이 합 = 점수. 같은 입력이면 같은 순위

### F-07 필수 조건 필터
- **설명**: 예산·통근 한도·월 총비용 한도를 넘는 동은 제외하고, 이유와 "얼마나 풀면 되는지"를 보여준다. 통과가 3곳 미만이면 아깝게 탈락한 동을 함께
- **데이터**: `excluded[].violations[]`, `near_misses[]`, `notes[]`
- **화면**: 순위표 아래 "제외된 동 n곳" 접기 목록 (이유, 완화 제안). 아깝게 탈락한 동은 강조
- **수용 기준**: 실거래가 5건 미만인 동은 예산으로 제외하지 않고 "예산 확인 불가"

### F-08 지도
- **설명**: 후보 동의 대표 지점을 점수 색으로, TOP 3 는 번호 핀, 목적지는 별도 핀, 제외된 동은 회색
- **데이터**: `ranked[]`·`excluded[]` 의 `lon`/`lat`, `destination`
- **화면**: OpenStreetMap 타일 + Leaflet (키 불필요). 선택한 동 강조, 팝업에 요약
- **수용 기준**: 지도·순위표·산점도의 선택이 서로 연동된다

### F-09 트레이드오프 산점도
- **설명**: 가로 월 총비용, 세로 통근 시간. 둘 다 더 나은 동이 없는 동(파레토)을 강조해 "시간 vs 돈" 선택지를 보여준다
- **데이터**: `scatter[]`
- **화면**: 점 = 동, 파레토 점 연결선, TOP 3 라벨, 데이터 부족(추정) 점은 속 빈 원
- **수용 기준**: 파레토 판정이 코드와 같다 (테스트 `test_pareto`)

### F-10 TOP 3 비교
- **설명**: 상위 3곳을 나란히. 월 총비용을 월세 중앙값·보증금 환산·교통비로 나눠 보여준다
- **화면**: 카드 3장 — 월 총비용 분해, 표본 수, 통근(분·수단·노선·환승, **카카오맵 경로 링크**), 가까운 역·도보, 편의시설·주점 수, 플래그, "이 동네 매물 보기"(외부 지도·부동산 서비스 링크, 매물은 추천하지 않음)
- **수용 기준**: 모든 숫자 옆에 단위, 하단에 출처·기준 시점

### F-11 순위 변동 설명
- **설명**: 조건을 바꾸면 순위가 어떻게, **왜** 바뀌었는지 요인별 점수로 보여준다 (시연 핵심 장면)
- **데이터**: `diff.moves[]`, `diff.overtakes[].by_factor`, `diff.weight_change`
- **화면**: 순위 변동 목록(▲▼), 추월 쌍마다 요인별 격차 변화 막대 (+/− 색 구분), 가중치 변화
- **수용 기준**: 요인별 변화 합 = 격차 변화 (테스트로 보장)

### F-12 가정 질문
- **설명**: "통근 30분 이내면?"처럼 물으면 결과만 보여주고 실제 조건은 유지한다
- **데이터**: `interpretation.what_if`, `result.what_if`
- **화면**: "가정" 배지가 붙은 결과와 안내 띠("실제 조건은 그대로입니다. 바꾸려면 '통근 30분 이내로 바꿔줘'처럼 말해 주세요"), "현재 결과로 돌아가기"
- **수용 기준**: 가정 후 세션 상태가 바뀌지 않는다 (테스트 `test_what_if_does_not_commit`)

### F-13 상충 감지
- **설명**: 함께 '중요' 이상으로 올린 두 요인이 후보 동에서 반대로 움직이면 숫자와 함께 알리고 되묻는다
- **데이터**: `tradeoffs[]`
- **화면**: 결과 위 안내 띠 ("편의시설이 많은 동일수록 주점도 많습니다 · 상위 25% 동 주점 중앙값 n개")

### F-14 결과 설명
- **설명**: Gemini 가 엔진이 계산한 숫자만으로 4~6문장 설명. 설명 속 숫자를 코드가 검사해 엔진 결과에 없는 숫자가 있으면 다시 쓰게 하고, 그래도 틀리면 코드 템플릿 설명으로 바꾼다
- **데이터**: `message.text`, `message.source`
- **화면**: AI 말풍선. `source=template` 이면 작은 "자동 요약" 표시
- **수용 기준**: 설명에 매물 추천이 없고, 실거래가는 "시세 참고용"이라고 밝힌다

### F-15 불확실성 표시
- **설명**: AI 결과의 오류·불확실성을 숨기지 않는다
- **화면 요소**
  - 배지: "월 총비용 데이터 부족"(중앙값으로 채움), "예산 안 거래 26/69건", "예산 확인 불가", "통근 데이터 없음"
  - 역 도보 시간 옆 "추정"
  - 하단 출처 목록 (`sources`), 실거래 기간 (`rent_period`), "실거래가는 과거 계약 기준 시세 참고용"
  - 확인 불가 조건 체크리스트 (F-02)
- **수용 기준**: 시연 대본의 모든 화면에서 출처와 기준 시점이 보인다

### F-16 현재 조건 요약 · 새 대화
- **화면**: 상단에 목적지, 필수 조건 칩(보증금 ≤ 1,000만, 월세 ≤ 60만, 통근 ≤ 50분), 요인 단계 칩(색 = 단계). "새 대화" 버튼 → 새 세션
- **데이터**: `interpretation.state`, `GET /api/sessions/{id}`

### F-17 동 상세
- **화면**: 지도·표·산점도에서 동을 고르면 세 화면에서 함께 강조되고, "상위 3곳 비교" 탭의 마지막 칸에 그 동의 카드(F-10과 같은 내용)가 들어간다

## 4. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 재현성 | 같은 상태·같은 데이터면 같은 순위 (점수 계산은 코드) |
| 응답 시간 | 저장된 지역: 한 턴 20초 안 (대부분 설명 생성). 처음 보는 지역: 수 분, 진행 로그로 안내 |
| 개인정보 | 실명·연락처 등을 입력하지 않도록 첫 화면에 안내. 외부 AI 에 보내는 것은 발화와 계산 결과뿐. 시연 데이터는 가상 페르소나 |
| 키 보안 | API 키는 서버 `.env` 에만, 응답·로그·캐시에 키를 남기지 않음 |
| 출처 표기 | 모든 수치에 출처와 기준 시점 |
| 브라우저 | 최신 Chrome·Edge, 데스크톱 1280px 이상 기준 (모바일은 세로 배치로 깨지지 않을 정도) |
| 장애 대응 | 시군구 수집 실패·통근 API 한도 초과 시 해당 부분만 빼고 계속, 로그에 표시 |
